
# ❤️ -Love-AI-Analyze-

Love Analysis is a simple web-based project that provides a fun and interactive way to analyze compatibility between two names.

# 🚀 Features

* ❤️ Name-based love compatibility analysis
* 🎨 Simple and attractive user interface
* 📱 Responsive design
* ⚡ Fast and easy to use
* 🌐 Built using basic web technologies

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## ▶️ How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Enter the required names.
5. Click the analyze button and view the result.

## 🎯 Purpose

This project was created as a beginner-friendly web development project to practice HTML, CSS, JavaScript, DOM manipulation, and interactive UI development.

## ⚠️ Disclaimer

The result generated by this project is **for entertainment and educational purposes only**. It does not scientifically or accurately measure love, relationship compatibility, personality, or future outcomes.
